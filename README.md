# 匿名意见箱

不记名网页。填写的人不用留姓名、邮箱、工号；结果表里也不写 IP 和设备信息。

线上地址（发布后）：https://wentaoz.github.io/anonymous-survey/

## 怎么用

1. 把上面的链接发给要填的人。
2. 按 [setup.html](setup.html) 用免费 Google 表格接上收集箱，大约 3 分钟。
3. 只在那张表里看意见。表头是 `id / day / category / impact / message`。

## 匿名边界

同事在结果里看不到是谁写的。

打开网页时，GitHub 的访问日志仍可能有 IP；点提交时，Google 服务器也会收到这次请求。这两处都不会写进意见表。若有人在正文里写「我是张三」，那就破功了。
